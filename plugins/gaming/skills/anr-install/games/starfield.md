# Starfield

- **Store and version:** any.
- **Renderer:** D3D12.
- **Exe folder:** the folder with `Starfield.exe`.
- **Proxy:** `dxgi.dll` (the OptiScaler wiki also lists `d3d12.dll`).
- **DLSS-G in game:** yes. The OptiScaler wiki lists the Nukem's path and "DLSSG via SL" as working.

## Spoof recipe

Tier 1 on non-RTX-40/50 GPUs. The [OptiScaler wiki page](https://github.com/optiscaler/OptiScaler/wiki/Starfield) (reported, RX 9070 XT, OptiScaler 0.9.4) notes no spoof problems.
