# New page

In plain words: build a page or artifact from a brief, deriving every value
before writing any CSS.

Run the steps in order. Each ends in a value you can paste. Read SKILL.md
step 1 first: job, mood and treatment feed them all.

1. **Type.** Take the ratio and density from the job row in
   references/type.md. Emit the nine-step ladder and the display clamp from a
   16px body.
2. **Headline.** Count the `h1` characters and size it off the bucket table
   in references/type.md, which also sets leading and the 300-unit weight gap.
3. **Palette.** Fix H from the named colour, else the mood, else the job row,
   per references/color.md. Emit the four layers at constant H, the twelve-step
   accent ramp, and all eight states of every interactive element.
4. **Space and layout.** Emit the ten-step ladder, apply step 1's density
   operator, and set the grid track, per references/space-and-layout.md.
   Treatment sets how far this step goes.
5. **Motion.** Take a duration and an easing by case from references/motion.md.
   Nothing here is chosen by feel.
6. **Thresholds.** Clear every floor in references/thresholds.md before you
   render.
7. **Critique.** Run references/critique.md in full: capture, hand the PNGs to
   a fresh agent, take back the filled verdict table, fix every `present` row,
   recapture. Two rounds, then ship, carrying any still-present row into the
   report.

Stop only when step 7 returns a written verdict.
