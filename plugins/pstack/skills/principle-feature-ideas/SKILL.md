# Feature ideas

Study the current project and its user's workflow before you propose features.

- State who benefits and what becomes better for each idea.
- Explore small improvements, medium features, and ambitious directions.
- Keep ambitious ideas when their user value is clear. Separate known facts from assumptions about feasibility.
- Check whether each feature already exists or is in progress. For an extension, name the specific missing behavior.
- Keep implementation design, task scope, and task order for later work.

Use the [Feature ideas playbook](../poteto-mode/playbooks/feature-ideas.md) for the workflow and brief format.
