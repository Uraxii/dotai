# Answer <question kind>

Use for "<user words>". Not for a change; see build-and-verify.
The deliverable is a cited answer. Change no files.

1. Write the question as one sentence. Expect it to name one subject.
2. List the sources: <files, docs, logs>. Expect a list of paths.
3. Read each source. Expect a quote or a line reference for each claim.
4. Label each claim as read, measured, or inferred. Expect a label on each
   claim.
5. Run git status. Expect no changed files.

Do not edit a file to test a guess, because the deliverable is an answer.

Done when each claim in the answer cites a source.

**Reply:** answer, citations, what was not checked.
