# Restyle

In plain words: change values on a page that already exists, without
re-deriving the whole design.

1. Read job, mood and treatment off the page or the brief, per SKILL.md step 1.
2. Re-derive only the subsystem being changed, from its file in SKILL.md's
   reference index. Leave every other subsystem's emitted values where they
   are: a second ladder or a second ramp beside the first is worse than the
   value you set out to fix.
3. Run references/critique.md in full. The critique step is not optional here
   either. A changed value moves the render, and the author is still the worst
   reader of it.
